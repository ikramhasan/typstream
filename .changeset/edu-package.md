New package: the Typst vocabulary for teachers' documents (#23). Templates (worksheet, quiz, exam, lesson plan, handout), numbered questions with points and totals, multiple choice, true/false, matching, blanks, answer lines and spaces, worked answers and an answer key shown only with `sys.inputs.showAnswers`, callouts, rubrics, student fields, number lines, graph paper, coordinate planes and chemistry (`ce`). Every function renders in the paged and HTML targets and in English, Arabic and Bengali. Packaged as a `TypstreamPlugin` with CSS and a prompt catalogue generated from the doc comments.
