A rubric is a plain `#table` now: the prompt teaches it (a header row, the points in each level's heading), so every cell, its headings included, is text to edit on the page. `rubric` still compiles for documents written with it, but is no longer in the prompt's catalogue or the editor's insert menu. In the visual editor a component's choices, yes/no and numbers are controls on its bar (a callout's kind, a question's points, a multiple choice's correct option), a chemical formula's field opens on a click, `matching` can be inserted, and edu's "Show answers" switch (`EditorFacet.switches`) shows the answers on the pages to edit there.
